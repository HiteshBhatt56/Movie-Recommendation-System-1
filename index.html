Movie Recommendation System

Find movies similar to your favorites using content-based filtering, TF-IDF and cosine similarity.

About the Project

This educational recommendation system compares movie genres and descriptive features to identify movies with similar content.

PythonPandasScikit-learnTF-IDFCosine Similarity

Try the Recommendation Demo

The GitHub Pages version runs the recommendation logic directly in the browser using the included demo dataset.

How It Works

1Movie metadata
2TF-IDF vectors
3Cosine similarity
  1. Combine genres and descriptions into text features.
  2. Convert the text into TF-IDF numerical vectors.
  3. Measure similarity between movie vectors using cosine similarity.
  4. Return the highest-scoring movies as recommendations.

Run the Python Version

pip install -r requirements.txt

python movie_recommender.py --movie "Inception"

python movie_recommender.py --list-movies

For your own dataset, use a CSV containing at least title and genres. Optional columns: overview, cast and director.
